# Licence texts

Canonical texts of the licences that apply to den's data sources, copied unchanged from
[spdx/license-list-data](https://github.com/spdx/license-list-data) at commit `31ba1a50e5397e00a304dbadc76531740e89ee48`
(release v3.29.0), `text/<SPDX id>.txt`. `den licences` copies the ones in use into `data/LICENSES/texts/`; which source
uses which, and why, is recorded in `den/licences.py`.
